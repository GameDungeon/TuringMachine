# Turing Machine Direct Sim
This is a very optimized direct sim for turing machines.

## Instructions
While this is a rust project, a python script `./turing.py` is provided for easy use.

**Single Run**
> `python turing run "1RB1RA_0LC1LE_1LD1LC_1LA0LB_1LF1RE_---0RA" --steps 10e9`

**Bulk Run**
> `python turing bulk -f "./machines.txt" --steps 10e9`
